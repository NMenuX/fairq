# FairQ Counter Dashboard

React frontend for the FairQ Bank Queue Management System - Staff Counter Dashboard.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open http://localhost:5174 in your browser

## Environment Variables

Create a `.env` file (optional):
```
VITE_API_URL=http://127.0.0.1:8001
```

## Features

- **Dashboard**: Live queue view with DWFQ suggestions
- **Metrics**: Fairness metrics and analytics
- **All Tokens**: View and search all tokens with filters

## Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.
